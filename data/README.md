# Data

> **All datasets in this repository are entirely simulated.**

No real patient data, clinical trial data, or proprietary compound information
is used anywhere in this repository. Every dataset is generated by a dedicated
simulation script (`01_simulate_data.R` or `01_simulate_data.py`) in the
corresponding project directory.

## Purpose

The simulated datasets serve two purposes:

1. **Demonstrate analytical workflows** — the data structures, sampling designs,
   and noise levels are representative of real Phase 1/2 PK and PK/PD studies.
2. **Enable parameter recovery verification** — the true parameter values used
   to generate each dataset are documented at the top of every simulation script.
   A reviewer can inspect whether the estimation step recovers the known truth.

## Reproducibility

All random seeds are fixed. Re-running any simulation script produces
bit-for-bit identical output. Seeds are set in the script header and chosen to
be mnemonically linked to the project year (e.g., `set.seed(2024)`).

## File Format

CSV files follow a NONMEM-compatible column convention where applicable:

| Column | Meaning |
|--------|---------|
| `ID` | Subject identifier (integer) |
| `TIME` | Nominal time since first dose (hours) |
| `DV` | Observed dependent variable (concentration or effect) |
| `AMT` | Dose amount (mg), NA for observation rows |
| `EVID` | Event ID: 0 = observation, 1 = dose |
| `MDV` | Missing DV flag: 1 = row excluded from likelihood |
| `CMT` | Compartment number |
| Species-specific covariates | `BW`, `AGE`, `SEX`, `DOSE` as appropriate |
